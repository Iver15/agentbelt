### Проверенные сценарии

- В изолированном экземпляре на 47812 переименование EU-1 обновило назначения Claude/Codex/pi и сохранило пароль. Дублирование скопировало учётные данные на сервере, оставило назначения и выбрало копию только для разового запуска. Занятое имя показало ошибку без закрытия формы.
- Удаление без замен не отправило форму. После выбора разных замен для Claude/Codex/pi удалённая запись исчезла, назначения и реальные генерируемые команды остались действительными. Сервер проверяет точный актуальный набор назначений, включая omp.
- Параллельное изменение прокси отклонило открытую устаревшую форму. Редактор не получил текущий пароль; keep/replace/remove, кодирование спецсимволов, ошибка записи и сохранение файла без изменений при отказах проверены отдельными регрессиями.
- При пустом назначении по умолчанию ни один маршрут не выбран автоматически, запуск выключен. Разовый выбор не меняет назначение. Сохранение назначения Codex оставило Claude без изменений. Переключение агента сохраняет его отдельный разовый выбор в текущей странице.
- Отсутствующий в тестовой оболочке Codex CLI выключил запуск. Создание тестового executable и ручная проверка обновили готовность. CLI не исполняется в ходе проверки. Разовый запрос запуска передал выбранные tool/proxy/dir и серверное место открытия; внешний iTerm-вызов в этом экземпляре заменён записью запроса в локальный файл.
- Добавление полями и URL, результаты 401/403, назначения после добавления, очистка URL/пароля и восстановление кнопок проверены повторно после обновления JavaScript.
- Tab переводит фокус между полями редактора; Escape закрывает диалог и возвращает фокус к кнопке «Изменить». Переходы Tab/Shift+Tab на границах замкнуты внутри формы; проверены оба направления и возврат фокуса после Escape. Поля имеют labels, ошибки — alert, результаты действий — status; фокус видим.

1. Подсказка «пароль сохранится» оставалась при выборе replace/remove. Теперь текст соответствует выбранному действию; повторная проверка формы подтвердила исправление.
